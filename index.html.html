02 · React Router 개념 구현 매핑
React Router (v6)본 프로젝트 구현설명
<BrowserRouter>currentRoute 전역 변수현재 활성 경로를 상태로 관리
<Link to="...">navigate('경로') 호출페이지 새로고침 없이 화면 전환
<Routes> / <Route>renderPage() switch 분기경로에 따른 컴포넌트 렌더링
useParams()routeParam 변수상품 상세 페이지의 :id 파라미터
useNavigate()navigate() 함수장바구니 결제 후 홈으로 강제 이동
03 · AI 활용 내역
🤖 Claude Sonnet 4.6
Anthropic · claude.ai

전체 HTML/CSS/JavaScript 코드 생성 및 UI 디자인에 활용하였습니다. React Router의 핵심 개념(BrowserRouter, Link, Routes, Route, useParams, useNavigate)을 순수 JavaScript로 재현하는 아이디어와 코드 구조를 AI가 제안하였으며, 야구용품 상품 데이터 구성 및 디자인 시스템 설계도 AI와 협업하여 완성하였습니다.
